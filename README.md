# -pro
本地优先的微信小程序：健身与饮食管理。BMR/TDEE 与三大营养素目标、136 条食物库、饮食与训练记录、趋势统计、JSON 备份回滚。数据全部存本机，零网络请求、零服务器成本。A local-first WeChat Mini Program for personal fitness &amp; nutrition tracking — BMR/TDEE and macro targets, food &amp; workout logging, trend charts, JSON backup. All data stays on your device: no server, no cloud, no cost.
