# 01 · 小主机选购与 Debian 12 系统安装

---

## 🛒 一、买什么机器

### 最推荐：畅网 N100 迷你主机

- **搜索关键词**：拼多多/闲鱼/淘宝搜 `"N100 迷你主机 8G 256G"`
- **价格**：¥250-350
- **配置**：Intel N100 (4核4线程) / 8GB DDR4 / 256GB M.2 SSD / WiFi6 + 千兆网口
- **功耗**：6-15W（一个月电费约 3-5 元）
- **为什么选它**：
  - x86 架构，Node.js / cloudflared 原生支持，零折腾
  - 性能远超需求（Xlover 后端仅用 ~200MB 内存）
  - 自带 SSD，比 TF 卡稳定 100 倍
  - 功耗极低，24 小时运行无压力

### 备选

| 型号 | 适合人群 |
|------|----------|
| 零刻 EQ12 (N100/16GB) | 预算充足，想留更多余量 |
| 树莓派 5 4GB | 喜欢 ARM 生态、有 GPIO 扩展需求 |

> ⚠️ **不推荐**树莓派 Zero / 3B 等老型号，性能太弱跑 Node.js 吃力。

### 选购清单

- [ ] N100 迷你主机 ×1
- [ ] 网线 ×1（连路由器，比 WiFi 稳）
- [ ] U盘 ×1（8GB+，装系统用）
- [ ] HDMI 线 + 键盘（仅装系统时用一次，装完走 SSH 无头管理）

## 💿 二、制作系统安装 U 盘（在 Windows 上做）

### 1. 下载 Debian 12 镜像

- 官网：https://www.debian.org/distrib/
- 选 **PC installer image** → `debian-12.x.x-amd64-netinst.iso`（约 600MB）
- 国内镜像加速：https://mirrors.tuna.tsinghua.edu.cn/debian-cd/current/amd64/iso-cd/

### 2. 用 Rufus 烧录 U 盘

- 下载 Rufus：https://rufus.ie/
- 打开 Rufus：
  - 设备 → 选你的 U 盘
  - 引导类型选择 → 选下载的 `debian-xx-netinst.iso`
  - 分区类型 → **GPT**
  - 点「开始」→ 确认擦除 U 盘
- 等 1-2 分钟烧完

---

## 🔧 三、安装 Debian 12 到小主机

### 1. 插 U 盘 + 网线 + HDMI + 键盘，开机

- 开机按 `F7` 或 `Del` 或 `F2`（不同品牌不同键，开机时看屏幕提示）进 BIOS
- Boot → 选 U 盘启动
- 选 `Graphical Install`（图形化安装，最简单）

### 2. 安装步骤（关键选项）

| 安装向导提示 | 选择 |
|-------------|------|
| 语言 | Chinese (Simplified) - 中文(简) |
| 区域 | 中国 |
| 键盘布局 | American English |
| 主机名 | `xlover` |
| 域名 | （留空） |
| Root 密码 | 自己设一个强密码，**记牢** |
| 新建用户全名 | `xlover` |
| 用户账号 | `xlover` |
| 用户密码 | 自己设，**记牢** |
| 磁盘分区 | **使用整个磁盘** → 选 `/dev/sda` → 将所有文件放在一个分区中 → 结束分区设定 |
| 软件包选择 | **只勾** `SSH server` 和 `standard system utilities`，**取消勾** `Debian desktop environment`（不装桌面，省 1GB+ 内存） |
| GRUB 引导 | 装到 `/dev/sda`（第一块硬盘） |

### 3. 装完拔 U 盘重启

安装约 10-15 分钟。完成后自动重启，看到 `xlover login:` 黑屏提示符即成功。

## 📡 四、配置 SSH 远程管理（装完就不需要键盘显示器了）

### 1. 在小主机上操作（最后一次用物理键盘）

```bash
# 用 xlover 账号登录后，切换到 root
su -

# 确认 SSH 已启动（安装时勾了 SSH server 应该已启动）
systemctl status ssh
# 如果没启动：systemctl enable --now ssh

# 查看小主机 IP
ip addr | grep inet
# 记下 192.168.x.x 这个地址

exit  # 退出 root
```

### 2. 在 Windows 上验证 SSH 能连上

打开 PowerShell：

```powershell
ssh xlover@192.168.x.x
# 输入密码，看到 xlover@xlover:~$ 即成功
```

✅ **以后所有操作都从 Windows SSH 远程做，小主机只要插电插网线即可。**

### 3.（可选）配置 SSH 密钥免密登录

在 Windows PowerShell：

```powershell
# 生成密钥（一路回车）
ssh-keygen -t ed25519 -C "xlover-admin"

# 把公钥传到小主机
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh xlover@192.168.x.x "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"

# 以后 ssh xlover@192.168.x.x 免密直接进
```

## 🔧 五、初始化系统（装完系统第一件事）

SSH 登录后执行：

```bash
# 切 root
sudo -i

# 更新系统
apt update && apt upgrade -y

# 装必备工具
apt install -y curl wget git vim ufw htop

# 配防火墙（只开 SSH）
ufw allow 22/tcp
ufw enable

# 设时区（国内）
timedatectl set-timezone Asia/Shanghai

# 验证
date  # 应显示 CST 时间
```

## ✅ 完成确认

```bash
# 在小主机上执行，全部显示 OK 即可
echo "=== 系统信息 ==="
uname -a              # 应显示 x86_64 GNU/Linux
cat /etc/debian_version # 应显示 12.x
free -h               # 应显示 ~8G 内存
df -h /                # 应显示 ~250G 硬盘
ip addr | grep "inet " # 应显示 192.168.x.x
systemctl is-active ssh # 应显示 active
```
