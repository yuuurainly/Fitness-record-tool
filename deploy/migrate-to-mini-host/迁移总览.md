## ⚡ 快速开始（如果你已经买好机器装好系统）

```bash
# 1. SSH 登录小主机后，先初始化环境
bash 02-环境初始化.sh

# 2. 把 Windows 上打包好的项目传上来（用打包迁移包.bat 生成）
#    假设传到了 ~/xlover-deploy.tar.gz
cd ~ && tar xzf xlover-deploy.tar.gz

# 3. 部署后端
bash ~/Xlover-Server/deploy/migrate-to-mini-host/03-部署后端服务.sh

# 4. 浏览器打开 Cloudflare 注册域名 + 绑定隧道（见文档04）
```

```

    ↓ 加密隧道

        └── database/xlover.db (SQLite，含全量迁移数据)
```

## ❓ 常见疑问

**Q: 为什么不用 Docker？**
A: Xlover 后端就一个 Node + SQLite，直接 PM2 守护最简单。Docker 多一层抽象反而增加调试难度。如果你想用 Docker 我也可以补一个 Dockerfile。

**Q: 小主机断电了怎么办？**
A: cloudflared 和后端都由 PM2 守护，开机自启（`pm2 startup` + `pm2 save`）。来电后自动恢复。

**Q: 数据会丢吗？**
A: SQLite 文件存在小主机硬盘上。另有 `backup-db.sh` 每日凌晨自动备份到 `~/xlover-backup/`，保留 30 天。

**Q: Cloudflare Tunnel 免费吗？**
A: 完全免费，流量无限。trycloudflare.com 临时域名也免费但每次重启会变；绑定自有域名后永久固定。
